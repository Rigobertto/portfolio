# Rode o repositório localmente

1. Clone o repositório:

   ```bash
   git clone https://github.com/rigobertto/portfolio
   ```

2. Acesse o diretório do projeto

   ```bash
   cd portfolio
   ```

3. Instale as dependências:

   ```bash
   pnpm install
   ```

4. Rode o servidor local:

   ```bash
   pnpm dev
   ```
